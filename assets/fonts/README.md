# Chapter ruler type

`noto-sans-sc-ruler-600.ttf` is a Google Fonts text subset of **Noto Sans SC**, weight 600, used only for the chapter navigation labels in `scroll-ruler.css`.

- Project: https://github.com/notofonts/noto-cjk
- Distribution: https://fonts.google.com/noto/specimen/Noto+Sans+SC
- License: SIL Open Font License 1.1; see `NOTO-SANS-SC-OFL.txt`.
- Subset text: `首页代表作品产品链路作品分类联系`.
- Downloaded: 2026-10-15, via the Google Fonts CSS API, font version v41.

The visible glyph surface uses a small vertical compression in CSS; the font file itself is not reshaped. If chapter labels change, refresh the text subset to include the new characters. The website loads the file locally, without visitor requests to Google Fonts.

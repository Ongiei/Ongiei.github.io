# Scene texture sources

The following textures are from Poly Haven and are available under CC0:

- [Oak Wood Planks](https://polyhaven.com/a/oak_wood_planks): `oak_wood_planks_Diffuse.jpg` and `oak_wood_planks_nor_gl.jpg`. The diffuse map was color adjusted toward pale honey oak for this scene.
- [Floor Tiles 04](https://polyhaven.com/a/floor_tiles_04): `floor_tiles_04_Diffuse.jpg` and `floor_tiles_04_nor_gl.jpg`.
- [White Stucco](https://polyhaven.com/a/white_stucco): `white_stucco_Diffuse.jpg` and `white_stucco_nor_gl.jpg`.

These are 1K maps. The scene uses the diffuse and OpenGL normal maps; texture repetition is controlled by world-space UVs in `FloorPlan3DScene.tsx`.
